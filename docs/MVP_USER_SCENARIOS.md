# 🛤️ 核心用户旅程

## **用户旅程1: 本地居民查看空气质量**

### **场景描述**
Sarah早上准备带孩子出门，想快速了解今天的空气质量是否适合户外活动。

### **用户旅程步骤**

#### **Step 1: 应用启动** ⏱️ 0-3秒
```
用户动作: 点击CLISAPP图标
期望结果: 
- 应用快速启动 (≤2秒)
- 显示Queensland全图
- 地图加载流畅无卡顿

用户心理: "希望应用能快速打开"
```

#### **Step 2: 定位到当前区域** ⏱️ 3-15秒
```
用户动作: 点击右下角定位按钮
系统响应:
- 请求位置权限 (首次使用)
- 获取GPS位置
- 地图移动到Sunnybank区域

用户心理: "想快速找到我的位置"
可能问题: GPS信号弱、权限拒绝
```

#### **Step 3: 查看区域信息** ⏱️ 15-25秒
```
用户动作: 点击Sunnybank区域边界
系统响应:
- 区域高亮显示
- 信息卡从底部滑入
- 显示PM2.5数值和健康状态

用户心理: "需要简单明了的健康建议"
期望: 快速理解空气质量状况
```

#### **Step 4: 理解健康建议** ⏱️ 25-35秒
```
用户动作: 阅读健康状态和建议
显示内容:
- PM2.5: 15 μg/m³
- 状态: 良好 (绿色)
- 建议: 适合户外活动

用户心理: "可以放心带孩子出门了"
决策: 继续计划的户外活动
```

### **成功标准**
- [ ] 整个流程35秒内完成
- [ ] 用户能正确理解空气质量状况
- [ ] 健康建议清晰易懂
- [ ] 无技术障碍影响体验

### **潜在问题与解决方案**
| 问题 | 解决方案 |
|------|----------|
| GPS定位失败 | 提供手动搜索地名的替代方案 |
| 数据加载慢 | 显示加载指示器和缓存机制 |
| 健康建议不明确 | 使用简单的颜色编码和直观语言 |

## **用户旅程2: 迁居者比较不同区域**

### **场景描述**
Mike正在考虑从Sydney迁居到Queensland，想比较Brisbane CBD、Gold Coast和Sunshine Coast的环境质量。

### **用户旅程步骤**

#### **Step 1: 应用启动和概览** ⏱️ 0-5秒
```
用户动作: 打开应用，观察Queensland全图
用户心理: "想了解Queensland的整体分布"
期望: 能看到主要城市的相对位置
```

#### **Step 2: 搜索第一个目标区域** ⏱️ 5-20秒
```
用户动作: 在搜索框输入"Brisbane CBD"
系统响应:
- 显示搜索建议 (Brisbane City, Brisbane CBD, 4000)
- 用户选择"Brisbane City"
- 地图飞行到Brisbane区域

用户心理: "搜索要精准快速"
期望: 准确找到目标区域
```

#### **Step 3: 查看Brisbane详细信息** ⏱️ 20-40秒
```
用户动作: 点击Brisbane City区域
系统响应:
- 显示详细信息卡
- PM2.5数据、人口、数据来源
- 记录或截图保存信息

用户心理: "需要可靠的数据用于决策"
关注点: 数据来源、更新时间、准确性
```

#### **Step 4: 比较其他区域** ⏱️ 40-90秒
```
用户动作: 重复搜索"Gold Coast"和"Sunshine Coast"
系统响应: 
- 快速定位到各区域
- 显示对应的空气质量数据
- 用户心理记录或对比

用户心理: "需要方便的比较功能"
改进点: 未来可添加收藏和对比功能
```

#### **Step 5: 切换到Suburb级别** ⏱️ 90-120秒
```
用户动作: 在Brisbane区域切换到Suburb层级
系统响应:
- 显示详细的Suburb边界
- 可查看具体Suburb的数据
- 如Sunnybank, South Bank等

用户心理: "想了解更具体的区域差异"
价值: 帮助做更精确的选择
```

### **成功标准**
- [ ] 能够流畅地搜索和比较多个区域
- [ ] 数据显示清晰，便于比较
- [ ] 搜索功能准确高效
- [ ] 层级切换功能正常工作

## **用户旅程3: 教师课堂演示**

### **场景描述**
Lisa老师在地理课上向学生演示Queensland的行政区划和环境数据，需要清晰的可视化展示。

### **用户旅程步骤**

#### **Step 1: 课堂准备** ⏱️ 课前
```
用户动作: 连接投影仪，打开应用
期望: 
- 界面清晰，适合大屏展示
- 操作简单，避免课堂技术问题
- 字体足够大，后排学生能看清
```

#### **Step 2: 展示Queensland全貌** ⏱️ 0-30秒
```
用户动作: 显示默认的Queensland全图
教学内容:
- 指出主要城市位置
- 说明LGA的概念
- 展示州的地理边界

学生反应: 对整体布局有直观认识
```

#### **Step 3: 行政层级演示** ⏱️ 30-90秒
```
用户动作: 切换LGA和Suburb层级
教学价值:
- 解释不同行政层级的概念
- 显示边界划分的差异
- 说明数据收集的不同尺度

学生学习: 理解行政区划的层次性
```

#### **Step 4: 具体区域分析** ⏱️ 90-180秒
```
用户动作: 搜索学生熟悉的区域 (如Ipswich)
教学内容:
- 展示本地区域的数据
- 解释环境数据的含义
- 讨论数据来源和可信度

学生参与: 对本地环境有新认识
```

#### **Step 5: 互动探索** ⏱️ 180-300秒
```
用户动作: 让学生提出要查看的区域
教学方式:
- 现场搜索学生家乡
- 比较不同区域的数据
- 引导学生思考环境差异的原因

学习效果: 主动参与，深化理解
```

### **成功标准**
- [ ] 界面适合课堂展示
- [ ] 操作简单，无技术门槛
- [ ] 数据展示教学价值高
- [ ] 支持互动探索

# 🧪 详细测试用例

## **测试用例组1: 基础功能测试**

### **TC-001: 应用启动测试**

#### **测试目标**
验证应用能在不同设备上正常启动并显示Queensland全图

#### **测试前置条件**
- 设备已安装CLISAPP
- 网络连接正常
- 设备性能: iPhone 12 / Samsung Galaxy S21

#### **测试步骤**
```
Step 1: 点击应用图标
Step 2: 等待应用加载
Step 3: 验证地图显示
Step 4: 检查界面元素完整性
```

#### **预期结果**
- [ ] 应用启动时间≤2秒
- [ ] Queensland全图正确显示
- [ ] 所有UI控件正常显示
- [ ] 无崩溃或异常错误

#### **测试数据**
- 测试设备: iOS 15.0+, Android 9.0+
- 网络环境: WiFi, 4G, 3G
- 测试次数: 每种配置至少3次

### **TC-002: 地图交互测试**

#### **测试目标**
验证地图的缩放、平移等手势操作功能正常

#### **测试步骤**
```
Step 1: 执行双指缩放 (放大/缩小)
Step 2: 执行单指拖拽平移
Step 3: 执行双击缩放
Step 4: 测试边界约束
Step 5: 检查性能表现
```

#### **预期结果**
- [ ] 手势响应时间≤100ms
- [ ] 缩放级别在合理范围内
- [ ] 平移限制在Queensland边界内
- [ ] 动画流畅，帧率≥30FPS

### **TC-003: 搜索功能测试**

#### **测试目标**
验证地名和邮编搜索功能的准确性和性能

#### **测试数据集**
```
有效地名: Brisbane, Sunnybank, Ipswich, Gold Coast
有效邮编: 4000, 4102, 4305, 4217
无效输入: XYZ123, 9999, 特殊字符@#$
部分匹配: Bris, 400, sunny
```

#### **测试步骤**
```
Step 1: 输入测试数据
Step 2: 验证自动联想功能
Step 3: 选择搜索结果
Step 4: 验证地图跳转
Step 5: 检查结果准确性
```

#### **预期结果**
- [ ] 自动联想≤500ms响应
- [ ] 搜索结果准确匹配
- [ ] 地图飞行动画流畅
- [ ] 目标区域正确高亮
