# 1. 引言（Introduction）

## 1.1 目的（Purpose）
本文档给出“CLISAPP（Climate Change Information System App）”的系统需求规格说明（SRS），用于指导产品设计、数据准备、开发与测试，并作为与客户对齐范围、验收标准与变更控制的依据。

## 1.2 范围（Scope）— 本学期 MVP
- 在移动端提供昆士兰（Queensland）范围内的交互式地图，支持 LGA（Local Government Area）与 Suburb/Locality 两级行政区边界的浏览与切换。
- 支持区域搜索、定位到当前区域、选区弹出信息卡。
- 信息卡展示人口（2021）、SEIFA（2021）与环境指标（首期为空气污染）；若 Suburb 缺失则回退到 LGA，UI 清晰标注数据分辨率与来源/年份。
- 不含：账号/收藏、历史留存、通知/健康告警、预测/健康关联、实时数据接入（留待后续阶段）。

## 1.3 读者对象（Audience）
客户代表、产品经理、数据工程师、移动端工程师、GIS 工程师/分析师、QA 测试工程师、UI/UX 设计师、项目管理与运维人员。

## 1.4 参考资料（References）
- 项目 Pitch、Proposal 文档与历次客户/组会纪要（2025-08–09）。
- ABS/QLD DES/BOM 等公开数据源规范与元数据说明。

## 1.5 定义与缩写（Definitions）
- LGA：地方政府区；Suburb/Locality：郊区/地名级行政单元。
- SEIFA：Socio-Economic Indexes for Areas（以 2021 年口径为准）。
- MVP：最小可行产品；MoSCoW：Must/Should/Could/Won’t。

# 2. 总体描述（Overall Description）

## 2.1 产品透视（Product Perspective）
CLISAPP 是一款客户端为主、离线友好的移动应用：
- 上游：QGIS 数据处理 → GeoPackage/GeoJSON/MBTiles；必要时由服务端通过 TileServer GL/CDN 提供向量切片（MVT）。
- 客户端：React Native + MapLibre GL，渲染 LGA/Suburb 边界、多指标图层与信息卡。

## 2.2 用户类型与特征（User Classes）
- 普通居民（Primary）：快速查看本地环境与社会经济概况。
- 教育/宣传人员（Secondary）：课堂或科普展示。
- 内部管理员（Ops）：数据发布、版本管理与回滚。

## 2.3 运行环境（Operating Environment）
- iOS 15+/Android 9+；中端机型在主缩放级别保持 30FPS+。
- 可能离线或弱网环境，需具备一定离线可用性。

## 2.4 设计约束（Design Constraints）
- 本学期时间与人力限制 → 以静态/半静态数据与地图交互为主。
- 法规/合规：遵循开源许可与数据使用条款；App 隐私弹窗与权限合规。

## 2.5 假设与依赖（Assumptions & Dependencies）
- 可获取完整且一致的昆士兰 LGA/Suburb 边界数据与 2021 人口、SEIFA 数据；
- 空气污染数据具备 LGA 级最小分辨率；
- 客户确认本期不做账号、通知、实时 API 与预测功能。

# 3. 外部接口需求（External Interface Requirements）

## 3.1 用户界面（UI）
- 地图主页：
  - 顶部：标题 + 搜索框（支持地名/邮编建议）。
  - 地图：默认 LGA 视图；支持手势缩放/平移；角落显示比例尺与当前缩放级别。
  - 右上：图层/层级切换（LGA ↔ Suburb）、指标选择（降雨/气温/UV rating/air quality）。
  - 定位到我（首次需权限）。
  - 点击区域：弹出信息卡（区域名、层级、降雨/气温/UV rating/air quality，来源/年份/分辨率说明）。
- 数据说明页：列出数据来源、更新时间、口径/单位解释与免责声明。

## 3.2 硬件接口（HI）
- 移动终端 GPS/定位传感器（可选）。

## 3.3 软件接口（SI）
- 客户端可读取本地 MBTiles/GeoJSON；可从 HTTP 端点拉取 MVT/GeoJSON 与元数据 JSON。

## 3.4 通信接口（CI）
- HTTPS（TLS1.2+）；CDN 缓存静态瓦片与元数据；离线包通过下载任务获取。

# 4. 系统特性（System Features）
本节以 FR-xxx 编号给出功能性需求，并和用户故事 US-xx 关联；同时定义验收标准（AC）与基本用例流。

## 4.1 地图浏览与缩放（FR-001，US-06，Must）
**描述**：用户可对地图进行平移、缩放，查看昆士兰全域至 Suburb 级细节。  
**AC**：
- Given 打开应用，When 进入地图，Then 默认显示昆士兰全图（LGA 轮廓清晰）。
- 手势缩放/拖拽在主缩放级别下平均帧率 ≥ 30FPS。  
**用例主流程**：用户进入 → 默认 LGA 视图 → 缩放/平移；  
**备选流**：设备性能不足 → 自动降级简化样式。

## 4.2 行政层级切换（FR-002，US-07，Must）
**描述**：LGA 与 Suburb/Locality 两级边界切换。  
**AC**：切换后 1s 内完成渲染；切换不改变当前视口中心；图例/图层状态保持。

## 4.3 区域搜索（FR-003，US-08，Must）
**描述**：通过名称/邮编搜索并跳转至对应区域范围。  
**AC**：
- 输入“Sunnybank”“Ipswich”等可得到联想；
- 选择条目后视口平滑飞行至该区域边界并高亮。

## 4.4 选区信息卡（FR-004，US-09，Must）
**描述**：点击区域弹出信息卡，展示名称、层级、降雨/气温/UV rating/air quality、来源/年份/分辨率说明。  
**AC**：
- 信息卡 300ms 内出现；
- 所有字段存在或给出明确“暂无数据/回退到 LGA”提示；
- 单位、口径、年份与来源显示完整。

## 4.5 定位到我（FR-005，US-05，Should）
**描述**：授权后地图居中至用户所在 Suburb；失败时友好提示。  
**AC**：首次权限请求合规；失败时不崩溃并显示“无法定位”的说明。

## 4.6 分辨率回退与标注（FR-006，US-10，Must）
**描述**：当 Suburb 级指标缺失时，自动显示 LGA 值并在 UI 标注“使用 LGA 值（因 Suburb 缺失）”。  
**AC**：
- 缺失检测覆盖 100% 指标字段；
- 信息卡与图例均有明显标识；
- 具备“无任何可用数据”提示状态。

## 4.7 数据可用性视觉提示（FR-007，US-11，Should）
**描述**：在地图上以淡化/斜线等样式标识缺失区域，避免误点。  
**AC**：切换指标时样式同步；图例含解释。

# 5. 非功能需求（Non-functional Requirements）

## 5.1 性能（NFR-PERF）
- 首屏地图渲染 ≤ 2.0s（在中端机，热启动，网络良好）。
- 主视图交互帧率 ≥ 30FPS；切层与数据回退判断 ≤ 300ms。
- 搜索从输入到建议呈现 ≤ 500ms（本地索引或预取）。

## 5.2 可靠性与可用性（NFR-REL）
- App 崩溃率 < 1%/月；
- 离线模式可显示最近一次成功拉取的瓦片与元数据；
- 地图数据与元数据支持版本号与回滚。

## 5.3 可用性/可达性（NFR-UX/A11y）
- 主要控件触达面积 ≥ 44×44pt；色带对比度 WCAG AA；
- 提供数据缺失/回退的可读文案与图例解释。

## 5.4 安全与隐私（NFR-SEC）
- 仅在用户授权后使用定位；不采集个人敏感数据；
- 所有网络通信采用 HTTPS；第三方 SDK 合规审查。

## 5.5 兼容性（NFR-COMP）
- iOS 15+/Android 9+；不同 DPI 下边界与标注清晰；
- 适配深色模式（可延期）。

## 5.6 可维护性（NFR-MAINT）
- 关键配置（数据源 URL、色带、阈值）通过配置文件/远端元数据热更新；
- 地图与指标逻辑模块化，具备单元/集成测试。
